# Runner memory is a rewritten-from-source profile, not an accumulating belief store

ADR 0008 split durable memory into two LLM-fed halves: a deterministic **belief** store (`CoachingContext`, the M4-M10 learning loop) and an LLM **narrative** (`CoachNarrative`, re-grounded by a background `Consolidation` job), with a derived **preference profile** (M10) reranking the coach's next-steps by inferred behaviour. In practice that machinery produced a concrete failure. The belief loop accumulated *derived behavioral verdicts* — "ignores easy guidance", "adds quality when told to hold" — from single, often misread signals (a rest day read by the M7 classifier as `ignored`). A verdict, once written, hardened: it was reinforced by its own `observation_count`, re-surfaced into every later context pack, and replayed by the coach as a standing nag, run after run, long after the signal that spawned it was gone. The runner experienced a coach fixated on a conclusion it had invented and could not let go of.

The root cause is structural, not a tuning error. A memory that **stores its own derived conclusions** and is **handed its prior state to edit** has a feedback loop: yesterday's guess becomes today's input becomes tomorrow's hardened fact. Capping the counter, decaying by TTL, or improving the classifier all narrow the blast radius but leave the loop intact — the conclusion can still be wrong, still echo, still nag. The only way a wrong behavioral verdict cannot replay forever is for memory to be incapable of *holding* one.

## Decision

Replace the durable-memory half of ADR 0008 (the LLM narrative + the deterministic belief loop + the M10 derived-preference reranking) with a single **runner memory profile**: one `RunnerMemory` row per user holding a `RunnerMemoryProfile` of five named sections (Who you are / Limits & constraints / Goals & plans / What works for you / Lately), each a capped list of short plain-language lines, strict-coerced (`extra="forbid"`, per-section count and per-line length caps), human-readable and diffable.

Three properties are load-bearing:

1. **Memory holds no LLM behavioral verdicts.** It holds *stated* facts — what the runner told the coach (a constraint, a goal, a stated preference, an open thread) — plus soft, **non-gating** character. It cannot contain an inferred conclusion like "ignores easy days", so the incident's content cannot regenerate. Whether the last advice worked, and whether the runner is trending toward easier running, are **re-derived deterministically** at exchange time from the data layer (`time_in_zones`, `recent_training`, `discount_signals`, M7's raw outcome) — spoken fresh, confounder-adjusted, never nagged, and **never written into memory as a stored verdict**.

2. **The writer is rewritten-from-source, never handed its own prior profile (anti-echo).** Each update pass rebuilds the *whole* profile from scratch from the raw sources (prior reports, chat, check-in notes) plus the deterministic data layer. It never reads the stored profile. There is no stored counter or accumulator to poison: graduation to a permanent section (§1-§4) requires support from **≥2 distinct source exchanges, re-derived from the current source set every pass**. A durable fact survives because it is re-retrieved from the raw store each time (section-shaped retrieval — sparse durable sections scan the full history, the dense "Lately" section uses a bounded recent window), not because it persisted in memory. It ages out only when a later source supersedes or retires it. This makes the anti-echo guarantee a property of *input construction*, pinned by a CI test, not a behaviour we hope the model exhibits.

3. **Memory is the citable `Stated memory` tier, with prompt-enforced authority.** Unlike the (now-retired) narrative and unlike the corpus/user-materials reference tiers, stated memory is *grounded* — the coach may cite it ("you mentioned your knee"). Its authority is bounded by the v13 prompt addendum: it yields to this run's measured `DerivedMetric` on a factual conflict (a stated fact can be mistaken or fabricated) and never lowers the safety floor. The deterministic backstops are the existing medical-scope validator (rule 5) and the eval `memory_preserved_safety_surface` assertion. There is **no** "memory-is-not-evidence" validator rule — that would contradict the tier being citable.

Writer and reader both gate on `is_memory_prompt(COACH_PROMPT_ID)` (the new `coach_message_v13`) and the `COACH_MEMORY_ENABLED` kill switch, so the substrate ships inert and a single cutover flip turns on writing and reading together; rollback is the same one flip.

## Considered options

- **Keep the belief store + narrative, cap and decay harder.** Rejected: parametric fixes (counter caps, TTL decay, a better M7 classifier) shrink the incident but leave the feedback loop intact — a wrong verdict can still be written, hardened, and replayed. The fix has to remove the loop, not narrow it.
- **Store the profile but let the writer read and edit its prior version.** Rejected: that *is* the echo loop in a new shape. Reading the prior profile lets a once-written line persist on its own authority and drift from the sources. Rewrite-from-source is the whole guarantee.
- **A new deterministic preference signal to replace M10's reranking.** Rejected for this work: M10's job was derived behavioral reranking — the exact verdict-driven, nag-adjacent behaviour being eliminated. It is dropped, not replaced. The coach keeps M7's raw adherence outcome under the non-nag discipline. Preference-conditioned framing, if ever wanted, is a deliberate separate feature.
- **A "memory-is-not-evidence" validator rule, mirroring the narrative/corpus/materials guards.** Rejected: those tiers are non-grounding by design; stated memory is the grounded, citable tier. Forbidding citation would defeat its purpose. Authority tiering is prompt-enforced (the house precedent for every authority-tier rule), with the medical-scope floor and eval as the deterministic backstops.

## Consequences

- New persistence: a `runner_memory` table (one row per user) and the `RunnerMemoryProfile` schema. A background update pass (`memory_update.py` → `update_memory_job`, one hardcoded `claude-haiku-4-5` call per the auxiliary-path convention, token spend recorded on the per-user budget) rewrites the profile from source after each non-fallback report, gated as above.
- The coach reads the **whole** profile as a `memory` pack section (no retrieval/ranking/top-k — surfaced whole; if it ever grows too big, tighten the writer, never add retrieval). The v13 report it writes becomes a source for the next pass, closing the loop without ever feeding memory its own prior text.
- A later milestone retires `beliefs.py`, `belief_store.py`, `narrative_store.py`, `consolidation.py`, `preference.py` (M10) and drops the `CoachingContext` and `CoachNarrative` tables (the rows are retired/superseded and the raw sources still hold the truth, so no export). M7 `adherence.py` stays — it is independent of the belief store and its consumption is governed by the v13 non-nag discipline.
- **The deterministic data layer is untouched.** `RunnerBaseline`, training load, calibration, and the discount signals were never the problem — they re-derive from data every run and never harden. This ADR supersedes only the durable-memory (layer 3) half of ADR 0008; that ADR's raw-store, processed-artifacts, and working-context layers stand.
- Future reviews should not re-suggest a belief accumulator, a stored adherence counter, an LLM narrative the writer re-reads, or a memory-is-not-evidence rule: the rewrite-from-source profile and its verdict-free, citable, prompt-tiered contract are the design, not an accident.
