Data-Flow Graph

One run's context pack, every block traced to its source. Click a node: cyan = where it came from, amber = where it goes, and its real data opens on the right. Each field carries two chips: ↤ which stage wrote it and its fate — where it goes on the next hop. Drag to pan, scroll to zoom.

Key

How to read the graph. Each node is a stage in the data flow from Strava to the coach report; click any node to trace its lineage and open its real data on the right.

Node colour — what a node IS
Raw — an external input the pipeline starts from (the Strava API).
Code / fact — a deterministic computed value or an analysis/read-time stage. The facts the coach may cite.
DB — a stored table/row (Activity, DerivedMetric, …). The persisted truth the LLM never overrides.
Runner — runner-declared or runner-uploaded input (check-in, voice/stance, materials).
Memory — durable learned memory (beliefs, narrative, preferences). Mostly off by default now.
LLM — the single Anthropic model call and the report it writes.
Node state
▶
Start of chain — nothing precedes this node; it is a raw input the pipeline begins from.
Empty this run (dashed + dimmed) — computed from THIS capture: the node carries no active content for this run (absent, config-disabled, or emitted empty). It goes solid on a run/runner where it IS populated.
Edges — appear when you click a node
Came from (cyan) — the upstream lineage this node's data was built from.
Feeds (amber) — everything downstream that consumes this node.
Field chips — in the detail panel, two per field
↤
Source — which stage WROTE this field (click it to jump there).
→
forwarded — reaches the next node unchanged. The chip also names the destination (e.g. the model).
↝
transformed — consumed by the next stage and re-emerges under a different name.
▽
reduced — reaches the next node but lossily shrunk (rounded, downsampled, or digested).
◇
gated — conditional on the prompt version or the data. The chip says what happened for THIS run: ◇ gated:passed got through, ◇ gated:blocked did not.
✕
dropped — terminal; nothing downstream consumes it on the path to the report.
